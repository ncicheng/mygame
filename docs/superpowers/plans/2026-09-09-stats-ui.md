# 数据统计 + UI 优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 MyGame 添加数据统计面板（从现有状态派生战绩/资源/养成统计）并优化页面显示（顶部标题栏、卡片排版）。

**Architecture:** 纯前端派生（无 schema 改动）——统计从 fetchReports/fetchSieges/fetchChallenges/fetchResources/fetchGeneral/fetchArmyUnits 计算；UI 加顶部标题栏与统计卡。

**Tech Stack:** React 18 + Vite + TS、现有 data.ts/shared 类型。

## Global Constraints

- 领域词汇用 `CONTEXT.md`：战报/攻城/挑战/稀有材料/武将/兵/军团
- 统计全部从现有数据派生（不加表/RLS/后端）
- 顶部标题栏：游戏名「运筹帷幄」+ 玩家昵称 + 领地
- 统计卡放右栏，与现有卡片风格一致（.card/.trow）
- 中文注释；2 空格；复用前端测试基建

**Files:**

**Interfaces:**
- Consumes: `BattleReport[]`、`Siege[]`、`Challenge[]`、`Resources`、`General`、`Soldier[]`
- Produces:
  - `export interface GameStats { banditBattles: number; banditWins: number; banditWinRate: number; challenges: number; challengeWins: number; sieges: number; siegeWins: number; totalRare: number; troopCount: number; generalLevel: number; }`

- [ ] **Step 1: 写失败测试** `frontend/test/stats.test.ts`

```ts
test('computeStats 从战报/攻城/挑战/资源/养成派生', () => {
  const s = computeStats({
    reports: [{ victory: true } as BattleReport, { victory: false } as BattleReport],
    sieges: [{ result: 'attacker_win' } as Siege],
    challenges: [{ result: 'challenger_win' } as Challenge],
    resources: { rare: 25 } as Resources,
    general: { level: 3 } as General,
    troops: [{ count: 120 }, { count: 60 }] as Soldier[],
  });
  assert.equal(s.banditBattles, 2);
  assert.equal(s.banditWins, 1);
  assert.equal(s.challengeWins, 1);
  assert.equal(s.siegeWins, 1);
  assert.equal(s.totalRare, 25);
  assert.equal(s.troopCount, 180);
  assert.equal(s.generalLevel, 3);
});
```

- [ ] **Step 3: 实现 stats.ts**（computeStats 派生统计，banditWinRate = wins/battles）
