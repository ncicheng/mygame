# MyGame MVP — Implementation Plan

## Global Constraints

- 领域词汇一律用 `CONTEXT.md` 词汇表：武将、兵、部队、武器、大地图、战斗实例、对战模式、军团、城池、养成
- 尊重 ADR：0001 半实时战斗架构 / 0002 服务器权威自建后端 / 0003 永久世界+免战期
- 兵种表（1-15 级）：乡勇/弓手/刀盾手/铁骑/重甲步兵/弩兵/虎贲/铁浮屠/神机营/天策上将/镇国大将军/九天玄女兵/太古龙骑/修罗战鬼/混沌主宰
- 武器表（1-20 阶）：木矛/青铜剑/环手刀/横刀/长枪/弯刀/偃月刀/方天画戟/金刚剑/屠龙刀/倚天剑/轩辕剑/干将莫邪/太阿剑/混沌剑/诛仙剑/昆仑镜/盘古斧/东皇钟/天道权杖
- 战力比公式：战斗单位战力 = 武将加成 × 兵数 × 单兵战力（兵等级决定）＋ 武器加成（阶决定）；双方战力比 → 胜率曲线 + 随机；胜方轻损、败方重损
- 武将可装备任意阶武器、重伤不灭、升级/升星/技能；兵只能装备对应等级武器、是消耗品、招募消耗基础资源
- 大地图：网格格子图、持久世界、多开世界、小世界规模（数百格、几十玩家）
- 半实时：行军实时渲染，遇敌切战斗实例，战前布阵 + 观看自动战斗 + 手动武将技能
- 对战模式全在大地图上：1v1=挑战、混战=乱斗场、军团战=攻城
- 离线行军；双轨经济（基础资源+稀有材料）；极简账号（用户名+密码）；免战期新手保护
- 界面：UI 原型变体 C「运筹帷幄」布局（中央棋盘 + 左右卡片栏 + 底部行动点操作台）
- 技术栈：前端 React+Vite+TS+Canvas → GitHub Pages；后端 Node+TS+Express+Socket.IO → Render/Railway；Postgres；服务器权威
- MVP 不含多人对战（后续迭代）；第一版打野 PvE 验证核心链路

## Task 1 — 脚手架与部署管道

**What to build:** 建立 monorepo 项目骨架：frontend（React + Vite + TypeScript）、backend（Node + TypeScript + Express + Socket.IO）、shared 共享类型包。后端接通 Postgres。前端经 GitHub Actions 自动部署到 GitHub Pages。

**Blocked by:** 无

**Status:** ready-for-agent

- [ ] monorepo 结构（frontend / backend / shared）就绪，TypeScript 全栈
- [ ] backend 启动后可连接 Postgres 并返回健康检查
- [ ] frontend 显示 backend 健康检查结果，证明前后端连通
- [ ] GitHub Actions 在 push 到 main 时自动构建并部署 frontend 到 GitHub Pages
- [ ] 本地一条命令启动开发环境（frontend + backend 同时起）

## Task 2 — 账号与初始武将

**What to build:** 极简账号系统（用户名+密码）：注册、登录、会话。新玩家注册时自动获得初始武将（Lv.1 乡勇部队 + 1 阶木矛）和初始资源。用户有自己的持久存档。

**Blocked by:** 01 — 脚手架与部署管道

**Status:** ready-for-agent

- [ ] users 表：用户名、密码哈希、注册时间
- [ ] 注册/登录/登出 API，会话持久（token 或 cookie）
- [ ] 注册即赠送初始武将（乡勇部队）、初始资源
- [ ] 登录页/注册页 UI，流程可走通
- [ ] 登录后主界面显示自己的武将卡与资源

## Task 3 — 世界地图与指挥台框架

**What to build:** 持久大地图（网格格子图，数百×数百格规模可配）的世界状态与主界面框架。主界面采用 UI 原型变体 C「运筹帷幄」布局：中央棋盘网格 + 左卡片栏（武将/部队/养成）+ 右卡片栏（资源/战报/任务/军团）+ 底部行动点操作台。登录后进入自己的世界，地图上可见我方城池、敌方城池、野地、部队。

**Blocked by:** 02 — 账号与初始武将

**Status:** ready-for-agent

- [ ] 世界/tile 网格 schema（地形、城池、野地、部队位置）
- [ ] 拉取世界状态的 API（登录用户视角）
- [ ] 变体 C 主界面布局：中央棋盘 + 左右卡片栏 + 底部行动点操作台
- [ ] 地图网格渲染（Canvas 或 DOM 网格），地形区分，我方城/敌方城/野地/部队标记可见
- [ ] 行动点机制：显示当前行动点/上限，消耗规则就位

## Task 4 — 招募与资源

**What to build:** 双轨经济的基础资源线与兵种招募。兵种表（1-15 级兵种）。用粮草等基础资源招募兵种加入部队，兵是消耗品。部队编成卡实时反映兵数与资源余额。

**Blocked by:** 03 — 世界地图与指挥台框架

**Status:** ready-for-agent

- [ ] 兵种表（1-15 级：乡勇/弓手/刀盾手/铁骑/重甲步兵/弩兵/虎贲/铁浮屠/神机营/天策上将/镇国大将军/九天玄女兵/太古龙骑/修罗战鬼/混沌主宰）
- [ ] 资源表：粮草/铁材等基础资源，有产出或初始额度
- [ ] 招募 API：校验资源足够 → 扣资源 → 兵加入部队
- [ ] 招募 UI（操作台入口 + 招募弹窗/面板）
- [ ] 部队编成卡展示各兵种数量，资源卡随招募实时扣减
- [ ] 兵对武器的等级约束：兵只能装备对应等级武器（约束就位，验证在后续票）

## Task 5 — 半实时行军

**What to build:** 部队行军系统。玩家对选中部队下达行军命令（起点 → 目标格），服务器时钟推进行军，地图上部队逐格移动实时渲染。行军在离线时继续（离线行军）；战斗相关不在此票。

**Blocked by:** 04 — 招募与资源

**Status:** ready-for-agent

- [ ] 行军命令 schema（部队、起点、目标、出发时间、到达时间）
- [ ] 发布行军命令 API（校验部队归属、目标可达性）
- [ ] 服务器世界时钟推进行军位置，到达后状态落库
- [ ] 地图上部队位置随行军逐格移动的实时渲染（WebSocket 推送）
- [ ] 行军进行中可被选中查看、可取消返回

## Task 6 — 打野战斗闭环

**What to build:** 首个战斗实例引擎与打野玩法。野地（山贼营地）可在行进目标。部队行军至野地遭遇 → 冻结切入战斗实例 → 战前布阵 → 战力比公式自动结算 → 战报写入 → 胜利掉落稀有材料、战损落库。战斗实例引擎为长期资产，后续 1v1/混战/攻城复用。

**Blocked by:** 05 — 半实时行军

**Status:** ready-for-agent

- [ ] 野地 schema（位置、守军强度、稀有材料掉落、刷新）
- [ ] 战斗实例引擎：遭遇触发、实例创建、自动结算、结果回写大地图
- [ ] 战力比公式落地：战斗单位战力 = 武将加成 × 兵数 × 单兵战力（兵等级决定）＋ 武器加成（阶决定）；双方战力比 → 胜率曲线 + 随机；胜方轻损、败方重损
- [ ] 战前布阵 UI + 战斗过程展示（自动播放可加速）+ 手动释放武将技能（技能窗口）
- [ ] 战报写入战报卡，胜利掉落稀有材料到资源卡
- [ ] 战败时武将重伤回城（武将不灭），兵战损落库

## Task 7 — 三级养成

**What to build:** 三级养成基础线。武将（升级/升星）、兵（逐级解锁新兵种）、武器（强化/升阶，1-20 阶）。稀有材料用于武器强化与武将升星，消耗驱动打野与后续对战。养成结果体现到部队战力。

**Blocked by:** 06 — 打野战斗闭环

**Status:** ready-for-agent

- [ ] 武将表成长线：升级、升星、技能（战力加成随成长提升）
- [ ] 武器表（1-20 阶：木矛/青铜剑/环手刀/横刀/长枪/弯刀/偃月刀/方天画戟/金刚剑/屠龙刀/倚天剑/轩辕剑/干将莫邪/太阿剑/混沌剑/诛仙剑/昆仑镜/盘古斧/东皇钟/天道权杖），强化消耗稀有材料
- [ ] 兵种解锁：随进度逐级解锁 1-15 级兵种
- [ ] 养成 UI：左卡片栏养成卡可交互（升级/强化/解锁按钮 + 进度条）
- [ ] 武将可装备任意阶武器；兵只能装备对应阶武器（约束生效）
- [ ] 养成后部队战力变化可在部队编成卡与战斗中体现
