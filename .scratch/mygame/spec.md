# MyGame 规格 — 多人在线实时策略对战

## 一句话

基于持久大地图的多人在线实时策略网页游戏（帝国时代观感 + SLG 逻辑），玩家组建由武将率领的部队，在大地图上占地、行军、打野、挑战、乱斗与攻城。经 GitHub Pages + 自建 Node 后端面向互联网发布。

## 目标与非目标

- 目标：多人对战核心闭环（行军→遭遇→战斗实例→养成），长期养成价值
- 非目标：全实时微操（框选走位）、赛季重置、逐兵单体模拟、3D 画面

## 核心实体

- **武将**：独立英雄单位。可装备任意阶武器；可升级、升星、学技能；战斗中可手动放技能；战败重伤回城（不灭）；率领部队。
- **兵**：可招募的消耗品单位，1-15 级；只能装备与自身等级对应的武器；战斗战损后需补充。
- **部队** = 武将 + 其率领的兵（数量为可变量），是行军与战斗的基本单位。
- **武器**：1-20 阶装备，提供数值加成。武将任意阶可用；兵只能用对应阶。
- **大地图**：网格格子图，所有玩家共享的持久世界。
- **战斗实例**：部队在地图上相遇时冻结切入的独立战斗结算，独立模拟、结束回写大地图结果。
- **城池**：地图上的战略据点，可被占领、攻打，是军团战的核心目标。
- **军团**：玩家组成的联盟组织，拥有领地并进行军团战。

## 玩法骨架

- **半实时**：行军在大地图上实时渲染；遇敌冻结切入战斗实例结算；战斗为战前布阵 + 观看自动战斗 + 手动放武将技能（可加速）。
- **三种对战模式（全在地图上发生）**：
  - 1v1 = 挑战：向玩家发起挑战，对方同意后两军移至中立点开战斗实例
  - 混战 = 乱斗场：地图中立区域，进区即混战
  - 军团战 = 攻城：军团攻打敌对城池
- **等级碾压**：无职业克制，高阶兵数值更强；战力比公式（战斗单位战力 = 武将加成 × 兵数 × 单兵战力，武器阶提供加成；双方战力比 → 胜率曲线 + 随机；胜方轻损、败方重损）。
- **持久世界**：世界不重置；新手免战期（固定时长不可被攻打，可打野发育，前期资源加倍）。
- **离线行军**：行军/建造/招募离线继续；战斗需在线观看，离线遭遇自动结算发战报。
- **双轨经济**：基础资源（产出兵，量大持续消耗）+ 稀有材料（强化武器/升星武将，打野与战利品产出）。
- **极简账号**：用户名 + 密码。
- **三级养成**：武将（升级/升星）、兵（逐级解锁新兵种）、武器（强化/升阶）。

## 技术架构

- 前端：React + Vite + TypeScript，Canvas 渲染网格地图 → 部署 GitHub Pages
- 后端：Node + TypeScript + Express + Socket.IO，服务器权威世界模拟 → 部署 Render/Railway
- 存储：Postgres
- 实时：WebSocket（Socket.IO）
- 世界规模：数百×数百格，单世界几十玩家，世界可多开

## 发布

- 代码托管与 CI 发布：GitHub（Pages 托管前端静态资源）
- 后端：Render/Railway 免费层，Postgres 托管数据库

## MVP 垂直切片（第一版）

1. 极简账号（注册/登录）
2. 单世界地图渲染（网格 + Canvas）
3. 招募/出兵（基础资源消耗）
4. 半实时行军（命令 → 地图行军渲染）
5. 打野 PvE：地图野地 → 战斗实例 → 自动结算 → 掉落稀有材料
6. 三级养成基础线：武将升级、兵解锁、武器强化

后续迭代（不在 MVP）：1v1 挑战、乱斗场混战、军团与攻城、三种模式的地图触发。

## 界面方案（UI 原型验证结果）

- 主界面采用 UI 原型变体 **C · 运筹帷幄（桌游指挥台）**：中央棋盘网格 + 左右卡片栏（武将/部队/养成/资源/战报）+ 底部行动点操作台
- 原型文件 `ui-prototype.html` 为一次性资产，验证决策后归档到 throwaway 分支，不进入 main
